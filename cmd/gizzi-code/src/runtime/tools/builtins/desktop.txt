desktop - Provision and control a cloud Desktop Cloud sandbox.

Use this tool when you need a real desktop OS (Linux, Windows, or macOS) to:
- run a desktop application or browser,
- execute commands in a sandboxed shell,
- capture a screenshot of the desktop,
- upload or download files,
- or perform mouse/keyboard automation.

The desktop is provisioned through the Allternit Desktop Cloud API and is
associated with a bot. You must provide the bot_id each time. If no sandbox
exists, call action=provision first. Use the returned sandbox_id for subsequent
actions. Always call action=deprovision when you are done to release resources.

Actions:
- provision: create and start a desktop. Optional os (linux, windows, macos) and
  template_id. Returns sandbox_id, status, provider, host.
- shell: run a shell command inside the desktop. Requires command array.
- screenshot: capture the desktop screen. Returns a base64 PNG.
- files/download: download a file from the desktop by path.
- files/upload: upload base64 content to a path on the desktop.
- mouse: send a mouse action (move, click, scroll).
- keyboard: send keystrokes.
- deprovision: stop and delete the desktop sandbox.
- status: get the current desktop status and endpoint info.
