# Model Provider Disclosures

## Current model (BETA)

During the BETA period, Allternit Cloud does **not** sell bundled model credits or resell inference. Subscription tiers and credit balances shown in the console are **UI-only** unless explicitly marked live.

Model inference is currently provided through:

- **OpenRouter** — long-tail model coverage and emergency fallback.
- Future planned adapters: Together AI, Fireworks AI, DeepInfra, Groq, Cerebras, AWS Bedrock, Replicate, and direct OpenAI / Anthropic / Google routes.

## Required user-facing disclosures

Any page or feature that lets users invoke cloud models must display a disclosure similar to:

> **Model providers**
> Allternit Cloud routes inference requests to third-party model providers. During BETA, model access is provided through OpenRouter and other upstream adapters. Pricing and availability are subject to each provider's terms. See [model providers](/models) for details.

- Model output is generated by third-party providers; Allternit does not control the content.

## Transition to paid model credits

Before Allternit sells subscription tiers that bundle model credits, obtain explicit **OEM / embedded-service / reseller terms** from each upstream whose models will be included. See `upstream-reseller-terms-outreach.md` for the outreach kit.

Until those terms are signed, keep subscriptions UI-only or operate on a BYOK (bring-your-own-key) / operator-paid basis.
