# Admin Workspaces

Organization-scoped resource containers for enterprise tenants. Admin workspaces are distinct from the user-owned `workspaces` table: they are owned by an organization, gated to organization owners/admins, and carry their own member roster (`owner`, `admin`, `member`).

## Authentication

All endpoints require a Clerk JWT or enterprise bearer token with an active organization. The caller must be an `owner` or `admin` of that organization. Members without admin rights receive `403 Forbidden` (`insufficient_role`).

## Rate limits

The protected public API enforces a per-organization sliding-window rate limit. The default is **600 requests per minute** and can be overridden per organization by setting `organizations.api_rate_limit_rpm`. Excess requests return `429 Too Many Requests` with a `Retry-After` header.

```bash
# Example: raise the limit for a specific organization
sqlite3 "${ALLTERNIT_DATA_DIR}/allternit.db" \
  "UPDATE organizations SET api_rate_limit_rpm = 1200 WHERE id = 'org_123';"
```

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/v1/admin/workspaces` | Create a workspace |
| `GET` | `/api/v1/admin/workspaces` | List organization workspaces |
| `GET` | `/api/v1/admin/workspaces/:id` | Get a workspace |
| `PUT` | `/api/v1/admin/workspaces/:id` | Update a workspace |
| `DELETE` | `/api/v1/admin/workspaces/:id` | Delete a workspace |
| `GET` | `/api/v1/admin/workspaces/:id/members` | List workspace members |
| `POST` | `/api/v1/admin/workspaces/:id/members` | Add or upsert a member |
| `PUT` | `/api/v1/admin/workspaces/:id/members/:member_id` | Set a member's role |
| `DELETE` | `/api/v1/admin/workspaces/:id/members/:member_id` | Remove a member |

## Workspace fields

| Field | Type | Notes |
|-------|------|-------|
| `id` | string | UUID generated by the server |
| `name` | string | 1–128 characters, required |
| `description` | string \| null | Optional |
| `created_by` | string | User ID of the creator |
| `created_at` | string | ISO 8601 timestamp |
| `updated_at` | string | ISO 8601 timestamp |

## Create a workspace

```bash
curl -s -X POST "${ALLTERNIT_API_URL}/api/v1/admin/workspaces" \
  -H "Authorization: Bearer ${CLERK_JWT}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Engineering",
    "description": "Production agent workspaces"
  }'
```

The creator is automatically added as `owner`. Response: `201 Created`.

```json
{
  "id": "ws_01J8Z...",
  "name": "Engineering",
  "description": "Production agent workspaces"
}
```

## List workspaces

```bash
curl -s "${ALLTERNIT_API_URL}/api/v1/admin/workspaces" \
  -H "Authorization: Bearer ${CLERK_JWT}"
```

```json
{
  "workspaces": [
    {
      "id": "ws_01J8Z...",
      "name": "Engineering",

      "created_at": "2026-08-09T09:00:00Z",
      "updated_at": "2026-08-09T09:00:00Z"
    }

```

## Update a workspace

```bash
curl -s -X PUT "${ALLTERNIT_API_URL}/api/v1/admin/workspaces/ws_01J8Z..." \
  -H "Authorization: Bearer ${CLERK_JWT}" \
  -H "Content-Type: application/json" \
  -d '{"name": "Engineering — EMEA", "description": "EMEA production workspace"}'
```

## Manage members

Add a member with role `member` (default), `admin`, or `owner`:

```bash
curl -s -X POST "${ALLTERNIT_API_URL}/api/v1/admin/workspaces/ws_01J8Z.../members" \
  -H "Authorization: Bearer ${CLERK_JWT}" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "user_456", "role": "admin"}'
```

Change a member's role:

```bash
curl -s -X PUT "${ALLTERNIT_API_URL}/api/v1/admin/workspaces/ws_01J8Z.../members/user_456" \
  -H "Authorization: Bearer ${CLERK_JWT}" \
  -H "Content-Type: application/json" \
  -d '{"role": "member"}'
```

Remove a member:

```bash
curl -s -X DELETE "${ALLTERNIT_API_URL}/api/v1/admin/workspaces/ws_01J8Z.../members/user_456" \
  -H "Authorization: Bearer ${CLERK_JWT}"
```

Member endpoints return `204 No Content` on successful update or removal.

## Error codes

| Code | HTTP | Meaning |
|------|------|---------|
| `organization_required` | 403 | No active organization in the session |
| `insufficient_role` | 403 | Caller is not an organization owner/admin |
| `invalid_name` | 400 | Name is empty or longer than 128 characters |
| `invalid_role` | 400 | Role is not `owner`, `admin`, or `member` |
| `workspace_not_found` | 404 | Workspace does not exist in this organization |
| `member_not_found` | 404 | Member does not exist in this workspace |
| `rate_limit_exceeded` | 429 | Organization exceeded its public API rate limit |
