# Codex manual parity

The [Codex manual](https://learn.chatgpt.com/docs/codex-manual.md) covers configuration, sandboxing, authentication, models, tools, sessions, observability, governance, and security. Because the manual is large, the Allternit parity mapping is split into four parts:

- [Part 1 — Configuration, auth, models, and sandbox basics](./codex-manual-part1.md)
- [Part 2 — History, file opener, environment, tools, and workflows](./codex-manual-part2.md)
- [Part 3 — Plugins, skills, MCP, sessions, and UI settings](./codex-manual-part3.md)
- [Part 4 — Security, compliance, telemetry, and advanced controls](./codex-manual-part4.md)

Each part explains the original Codex concept and maps it to the equivalent `gizzi-code` / Allternit CLI config, API endpoint, tool, or workflow. Codex-only SaaS behavior is documented as **Not applicable / roadmap** where no self-host equivalent exists.
