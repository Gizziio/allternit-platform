# Grok Bot (x.ai/bot) Audit — Phase 1

**Goal:** Reverse-engineer the public UX and feature set of x.ai/bot (Grok Bot) and produce an integration plan for Allternit surfaces.

## Scope
1. Research public information about Grok Bot: x.ai/bot landing page, X posts, demos, and any accessible documentation.
2. Identify core UX patterns: packaged bots, session tabs in a left rail, agent session lifecycle, bot marketplace, composer integration.
3. Compare with Allternit's existing Agent Hub, OpenMausBot integration, and session surfaces.
4. Produce a gap analysis and a concrete Phase 2 implementation plan for adding packaged bot sessions to Allternit as left-rail tabs.

## Deliverable
- `docs/agent-tasks/GROK_BOT_AUDIT_PHASE_1_NOTES.md` with YAML frontmatter.

## Constraints
- No code changes.
- No proprietary code forks; UX reference only.
- No git commits.
