# C2+C3 NOTES — wiki connector + artifact contracts

## What was built

- **`.pipeline/bin/wiki-ingest.sh`** (C2-R1/R2) — reads `TASTE_BRAIN`
  (default `$HOME/Desktop/allternit-brain`, silent skip when absent). Every
  `*.md` page gets a tolerant frontmatter parse (`type`/`status`/`domain`;
  no frontmatter = context page). `type: idea|pain` pages become
  `.pipeline/candidates/<slug>.md` with frontmatter `source_page`,
  `trust_tier: unverified`, `ingested_at`; all other types
  (runbook/decision/identity/domain/unknown) are context only. ALL pages are
  POSTed to memory (:3201, advisory) with source `wiki` and tier
  unverified/trusted as above; hash ledger in `taste/ingested.json` under
  `wiki:<relpath>` keys, updated only on 2xx. The connector never writes
  outside `.pipeline/` + memory, never writes back to the wiki, and never
  executes page content (all parsing is python3 data extraction).
- **`.pipeline/bin/dismiss.sh`** (C2-R3) — `dismiss.sh <slug-or-title>
  [note]` records `{title, dismissed_at, note}` in
  `.pipeline/dismissals.json` (candidate slugs resolve their title from the
  candidate file) and ingests the dismissal to memory as a `failed`-tier
  precedent, advisory like record-outcome.
- **`scout.cjs`** — loads `dismissals.json`, suppresses items whose
  normalized title (lowercase, alnum-only) matches a dismissal younger than
  14 days; suppression is logged to `errors.log` with slug/title/date cited
  and the item stays unseen. Briefs now carry C3-R1 frontmatter
  (`trust_tier: unverified`, `provenance_refs: [source URL]`).
- **`generate-spec.cjs` / `check-spec.sh`** — specs get frontmatter with
  `provenance_refs: [.pipeline/briefs/<slug>.md, sha256:<hash>]`; verdict
  review records get frontmatter (provenance: the spec path) on creation,
  rounds still append below it. The brief parser skips leading frontmatter.
- **`.pipeline/bin/contract-test.sh` + `.pipeline/taste/golden/`** — golden
  fixtures for brief/spec/review (spec and review fixtures generated by the
  real producers). Validates required keys (`schema_version: 1`, `trust_tier`,
  `provenance_refs`, `produced_by`, `produced_at`; extras allowed),
  regenerates the fixture spec byte-identically (produced_at masked), and
  validates live stubbed scout/check-spec output against the same contract.
- **`.pipeline/bin/wiki-test.sh`** — 38 checks: candidates from idea/pain
  only, injection page (C2-R1: candidate unverified, wiki byte-identical, no
  writes outside `candidates/` + ledger, nothing executed), ledger
  idempotency, absent-brain skip, memory-down advisory, dismissal
  recording/posting, scout suppression at 5 days vs re-surfacing at 15 days,
  then runs contract-test as its final block.
