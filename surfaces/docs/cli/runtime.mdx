## Overview

`gizzi runtime` discovers agent CLI executables that are available on a host, registers them as a local runtime entry, and reports their current status. This is useful for cataloging the agents installed on a workstation, CI runner, or remote machine that other Allternit tooling can dispatch work to.

A runtime entry records:

- The host the CLIs were discovered on (`localhost` by default).
- Each discovered CLI name, path, and version string.
- A status of `online`, `busy`, or `offline`.
- The last heartbeat and registration time.

The runtime registry is maintained in-process while the CLI is running; register a runtime whenever you want an up-to-date inventory of available agent CLIs.

## Command reference

| Command | Description |
| --- | --- |
| `gizzi runtime list` | List every registered runtime and the agent CLIs discovered on each host. |
| `gizzi runtime register [name] [host]` | Scan `host` for agent CLI executables and add or update the registry entry for `name`. |
| `gizzi runtime status [id]` | Show a summary of all runtimes, or detailed information for the runtime with `id`. |

## Usage examples

### List registered runtimes

```bash
gizzi runtime list
```

Output shows one runtime per host, a status icon, the host, and each discovered CLI with its version:

```text
Registered runtimes (1):

  ● local                localhost            1 CLI
      ✓ gizzi            0.0.0
```

### Register the local runtime

```bash
gizzi runtime register
```

This discovers CLIs on the local machine and stores them under the default name `local`.

### Register a remote host

```bash
gizzi runtime register build-box worker.local
```

The first argument is the runtime name; the second is the host identifier. If a runtime already exists for that host, the entry is updated with the latest discovery results.

### Show registry status

```bash
# Summary across all runtimes
gizzi runtime status

# Detailed view for a specific runtime
gizzi runtime status rt-localhost-1234567890
```

## Common arguments

The `runtime` subcommands do not accept additional flags beyond their positional arguments and `--help`.

| Argument | Applies to | Default | Description |
| --- | --- | --- | --- |
| `name` | `register` | `local` | Friendly name for the runtime entry. |
| `host` | `register` | `localhost` | Host identifier the CLIs were discovered on. |
| `id` | `status` | — | Specific runtime ID to inspect. When omitted, a registry summary is shown. |

## How discovery works

When you run `gizzi runtime register`, the CLI resolves known agent CLI executable names through the system `PATH` and records the first line of their `--version` output. No network calls are made; discovery is entirely local to the target host.

If no agent CLIs are found, the command prints a discovery report and exits without registering anything:

```text
Runtime host: localhost
Discovered at: 8/17/2026, 6:24:43 PM
Agent CLIs found: 0

  (none found)

No agent CLIs found — nothing registered.
```
