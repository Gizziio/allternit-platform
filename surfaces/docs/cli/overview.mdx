## What is Gizzi Code?

**Gizzi Code** is the unified CLI for the Allternit agentic runtime. It is distributed as the `gizzi` executable and powers the same engine that drives the platform web, desktop, and mobile surfaces.

The CLI gives you:

- An interactive **TUI** (terminal user interface) for agent conversations
- A **headless mode** for scripting and CI pipelines
- Built-in **tool execution**, **code editing**, and **browser automation**
- First-class **permission profiles** and **credential management**

## Quick example

Start an interactive session:

```bash
gizzi
```

Or run a single prompt and exit:

```bash
gizzi exec "Summarize the changes in the current git diff"
```
