## Overview

Inference hooks let organization owners and admins attach custom HTTP endpoints that run immediately before and after LLM inference. Pre-hooks can inspect and mutate the request body; post-hooks can inspect and mutate the final response. This page focuses on the admin API for configuring hooks.

For a detailed explanation of hook behavior, payload format, and signature verification, see [Security: Inference Hooks](/security/inference-hooks).

## Base URL

```
https://api.allternit.com/api/v1/gateway
```

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/gateway/inference-hooks` | Get current hook configuration |
| `PUT` / `POST` | `/api/v1/gateway/inference-hooks` | Create or update hook configuration |
| `DELETE` | `/api/v1/gateway/inference-hooks` | Remove hook configuration |

## Authentication

All endpoints require a Clerk JWT and organization owner or admin role.

```bash
curl https://api.allternit.com/api/v1/gateway/inference-hooks \
  -H "Authorization: Bearer $ALLTERNIT_TOKEN"
```

## Get configuration

```bash
curl https://api.allternit.com/api/v1/gateway/inference-hooks \
  -H "Authorization: Bearer $ALLTERNIT_TOKEN"
```

```json
{
  "organization_id": "org_01J",
  "pre_inference_url": "https://hooks.example.com/pre",
  "post_inference_url": "https://hooks.example.com/post",
  "abort_on_pre_error": true,
  "hook_secret": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```

## Set configuration

```bash
curl -X PUT https://api.allternit.com/api/v1/gateway/inference-hooks \
  -H "Authorization: Bearer $ALLTERNIT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "pre_inference_url": "https://hooks.example.com/pre",
    "post_inference_url": "https://hooks.example.com/post",
    "abort_on_pre_error": true
  }'
```

If no hook secret exists, one is generated automatically and returned in the response.

## Remove configuration

```bash
curl -X DELETE https://api.allternit.com/api/v1/gateway/inference-hooks \
  -H "Authorization: Bearer $ALLTERNIT_TOKEN"
```

```json
{
  "deleted": true,
  "organization_id": "org_01J"
}
```

## Request body fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `pre_inference_url` | string | no | URL called before inference. |
| `post_inference_url` | string | no | URL called after inference. |
| `abort_on_pre_error` | boolean | no | When `true`, non-2xx pre-hook responses abort the request. |

## Error codes

| HTTP status | Code | Meaning |
|-------------|------|---------|
| 400 | `allternit.invalid_request` | Malformed hook URL or missing organization. |
| 403 | `allternit.insufficient_role` | Caller is not an owner or admin. |
| 500 | `allternit.internal_error` | Internal gateway error. |
