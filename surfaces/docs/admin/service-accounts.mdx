# Service Accounts

Service accounts are machine identities that receive scoped API keys. They are useful for CI/CD pipelines, background workers, and integrations that should not use a personal user token.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET    | `/api/v1/admin/service-accounts` | List service accounts |
| POST   | `/api/v1/admin/service-accounts` | Create a service account |
| GET    | `/api/v1/admin/service-accounts/:id` | Get details |
| PATCH  | `/api/v1/admin/service-accounts/:id` | Update |
| DELETE | `/api/v1/admin/service-accounts/:id` | Delete |
| POST   | `/api/v1/admin/service-accounts/:id/rotate` | Rotate API key |

## Scoping

Each service account can be restricted to specific workspaces and RBAC roles. Rotate keys regularly from the admin dashboard or CLI.
