# Migrate from OpenAI

Allternit's `/v1/chat/completions` endpoint is wire-compatible with OpenAI. In most cases you only need to change the base URL and API key.

## Base URL and authentication

| OpenAI | Allternit |
|--------|-----------|
| `https://api.openai.com/v1` | `https://api.allternit.com/v1` |
| `Authorization: Bearer sk-...` | `Authorization: Bearer $ALLTERNIT_API_KEY` |

## Chat completions

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.allternit.com/v1",
    api_key=os.environ["ALLTERNIT_API_KEY"]
)

response = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Hello"}]
)
```

## Model mapping

Allternit exposes normalized model IDs. You can also use policy aliases and let the gateway route to the best connected model.

| OpenAI model | Allternit equivalent |
|--------------|----------------------|
| `gpt-4o` | `auto` or `allternit-balanced` |
| `gpt-4o-mini` | `auto` or `allternit-balanced` |
| `o1-preview` | `allternit-reasoning` |
| `text-embedding-3-small` | `allternit-embedding-3-small` |

Use `GET /v1/models` to list available models for your workspace.

## Feature parity notes

- **Function calling**: Allternit supports `tools`, `tool_choice`, and `parallel_tool_calls`.
- **Streaming**: Server-sent events use the same format as OpenAI.
- **JSON mode / structured outputs**: Pass `response_format: { "type": "json_object" }` or a JSON Schema.
- **Vision**: Image URLs and base64 inputs are supported.
- **Assistants API**: Use Allternit [Sessions](/api/sessions) and [Agents](/api/agents) for equivalent behavior.

## BYOK and self-hosted models

If you want to keep using your existing provider contracts, add an external key in the dashboard and route requests through Allternit for governance and audit.
