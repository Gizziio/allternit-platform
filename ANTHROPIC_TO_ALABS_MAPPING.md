# Anthropic Academy → A://Labs Mapping

> **Goal:** Use Anthropic Academy's course architecture as a reference, then curate Allternit-platform-specific equivalents that teach our stack instead of Anthropic's.
>
> **Principle:** We adopt the *topic structure* and *pedagogical flow*, but write original content, examples, and capstones based on Allternit code, packages, and surfaces. No verbatim copying of Anthropic copy or media.

## Content generation rules

1. **No verbatim copy.** Titles, descriptions, and lesson copy are rewritten for Allternit.
2. **Preserve pedagogy.** Keep the logical progression (e.g., API → tool use → RAG → agents → MCP).
3. **Allternit examples only.** Use Allternit code paths, packages, CLI tools, and surfaces in code snippets and capstones.
4. **Reuse existing templates.** Generate content JSON and run `alabs-module-template/scripts/build.ts` to produce HTML.
5. **Quizzes and capstones.** Every module must have 3 quizzes and a capstone per the existing module requirements.
6. **Canvas sync ready.** Generated HTML files should follow naming convention `ALABS-{TIER}-{COURSE}-module{N}.html`.
