Module 5: Model Context Protocol

Learn how Allternit attaches external MCP servers to the Tool Belt, exposes its own registry as an MCP server, and secures remote connections with OAuth and tunnel auth.

5 lessons · ~45 minutes Source: cmd/gizzi-code/src/runtime/tools/mcp

Allternit as an MCP client

The Model Context Protocol (MCP) is an open standard for connecting agents to external data sources and tools. Allternit can act as an MCP client through the SDK's NativeToolBelt.attachMcpServer(). The method discovers an MCP server's tools and registers each one as a namespaced tool in the active ToolRegistry.

Inside gizzi-code, the canonical implementation lives in cmd/gizzi-code/src/runtime/tools/mcp/index.ts. It loads configured servers, connects via HTTP/SSE or stdio, lists tools, and converts each MCP tool definition into an AI SDK dynamicTool. The result is that a tool like read on the docs server becomes docs.read in the agent's tool registry.

typescript 
import { ToolRegistry } from '@allternit/sdk/ai-runtime/tools';
import { NativeToolBelt } from '@allternit/sdk/ai-runtime/tools/search';

const registry = new ToolRegistry();
const belt = new NativeToolBelt(registry);

const names = await belt.attachMcpServer({
  serverId: 'docs',
  listTools: async () => [
    {
      name: 'read',
      description: 'Read a document',
      inputSchema: {
        type: 'object',
        properties: { id: { type: 'string' } },
        required: ['id'],
      },
    },
  ],
  callTool: async (name, args) => {
    return { content: `Read ${name} with ${JSON.stringify(args)}` };
  },
});

console.log(names); // => ['docs.read']
const tool = registry.getTool('docs.read');
console.log(tool?.input_schema.additionalProperties); // => false
  • Namespace isolation. Every tool is prefixed with its server id to avoid collisions.
  • Strict schemas. Attached tools set additionalProperties: false so the model cannot invent parameters.
  • Execution proxy. The registry forwards calls to the server's callTool method.

Allternit as an MCP server

The platform can also expose its own tool registry as an MCP server. The API surface at cmd/allternit-api mounts an MCP endpoint at /mcp/server that speaks JSON-RPC 2.0 and supports initialize, ping, tools/list, and tools/call.

gizzi-code ships a bundled MCP catalog in cmd/gizzi-code/src/runtime/tools/mcp/bundled.ts. Bundled servers such as sequential-thinking, context7, and superpowers are merged with user-defined config at startup, and user config overrides any bundled entry with the same key. The routes in cmd/gizzi-code/src/runtime/server/routes/mcp.ts expose status, list, connect, disconnect, add, remove, and OAuth helpers for managing servers.

Both directions, one definition: A capability is documented once as an MCP tool and consumed either by Allternit agents or by external MCP clients.

Tunnel security and OAuth

Remote MCP servers can be fronted by an MCP tunnel with optional mTLS and OAuth checks. The policy is stored in mcp_tunnel_auth and is fail-open when no row exists, fail-closed once a row exists. Headers consumed by the Rust route include x-allternit-tunnel-id, x-allternit-client-cert-thumbprint, x-allternit-oauth-issuer, and x-allternit-oauth-audience.

OAuth is enabled by default for remote servers unless explicitly disabled with oauth: false. The flow uses PKCE or dynamic registration. If a server requires authentication, gizzi-code surfaces a toast instructing the user to run gizzi mcp auth <name>, opens the browser, waits for the callback, and finishes the token exchange.

Capstone: Add a custom MCP server

Build and connect an MCP server that exposes a capability Allternit agents can use.

Define the server

Create a local stdio MCP server that exposes one tool, e.g. weather.get_forecast, with a strict input schema.

Configure gizzi-code

Add the server to gizzi-code config under mcpServers with type: 'local', command, and args.

Verify attachment

Run gizzi mcp list and gizzi mcp tools <name> to confirm the tool appears namespaced in the registry.

Use in an agent

Ask an Allternit agent to invoke the tool and observe the MCP transport call the local server.
