# X launch formats

## Single post (default — the cannon-shot)

```
Introducing {Name} — {one-line superlative}.

{one concrete capability sentence with a number if we have one}.

Available today → {link}
```
Attach: one social card (render `templates/social-card.html`) or one <60s clip.

## Point-release post (Qwen/Kimi velocity gear)

```
{Name} {version} is out:

• {improvement, with number}
• {improvement}
• {fix}

{link}
```

## Thread (flagship moments only, keep to 3–4 posts)

```
1/ Introducing {Name}. {superlative}. {card or clip}
2/ {the one benchmark or demo that proves it}
3/ {what people are saying / partner note}
4/ Available {when}, {where}. {link}
```

Rules (from the labs):
- No exclamation marks. Plain prose, one idea per line.
- One link per post, always to the durable artifact (blog/README).
- Reply with availability details rather than cramming them into the announcement.
